# daily-log

シンプルな日記Webアプリケーションです。  
PCでは一覧とエディタを並べた2ペイン表示、スマートフォンでは1ペイン切り替え表示で快適に日記を記録・検索・閲覧できます。

---

## 主な機能

- **新規作成時のオートセーブ & 編集時の手動セーブ**:
  - 未登録の日付（新規作成モード）では、入力が止まると自動的に保存（オートセーブ）
  - 登録済みの日付（編集モード）では、本文変更時に赤文字で「`未保存`」を表示し、保存ボタンで手動保存
  - 本文が空欄（未入力・空白のみ）の場合は保存ボタンを無効化
- **カスタムカレンダー（青ドット表示・未来日制限）**:
  - 日記が保存されている日付の下に青いドットを表示
  - 前年・次年ボタンおよび年・月ドロップダウンによる高速な年月移動、「今日へ移動」ボタンを搭載
  - 明日以降（未来）の日付は選択できないよう制限
- **日付降順の一覧表示 & 自動読み込み**:
  - 左ペインに日付と本文プレビュー（1行）をエクスプローラー詳細表示風に一覧化
  - 一覧の行クリックやカレンダーの日付選択に応じて、該当日の日記を自動読み込み
- **キーワード検索**: 本文や日付に対するリアルタイム絞り込み検索（クリアボタン付き）
- **日記の削除**: 誤操作を防ぐ確認モーダルダイアログ付きの削除機能
- **レスポンシブ対応**:
  - PC（`768px` 以上）は左右2ペイン同時表示
  - スマホ（`768px` 未満）は「編集画面 ⇔ 一覧画面」の1ペイン切り替え表示（上段にステータスメッセージ用固定スペースを確保しレイアウト揺れを防止）
- **PWA（Progressive Web App）対応**: スマホの「ホーム画面に追加」からネイティブアプリのように起動可能

## 技術スタック

- **フレームワーク**: Next.js 16 (App Router) / React 19 / TypeScript
- **スタイリング**: Tailwind CSS v4（ダークテーマ基調）
- **ORM / データベース**: Prisma v6 + SQLite

---

## 環境変数（`.env`）とポート番号

プロジェクトルートの `.env` にデータベース接続先および待受けホストを設定します。  
ポート番号は **`3647`** で固定されています。

```env
DATABASE_URL="file:./diary.db"
HOST="100.88.57.78"
```

> Tailscale 等を経由してスマホから自宅PCへアクセスする場合は、`HOST` に Tailscale の IPv4 アドレス（または `0.0.0.0`）を指定してください。

## セットアップ・起動方法

### 1. 初回セットアップ（別環境へ移行した場合）

```bash
npm install
npx prisma migrate dev
```

### 2. 開発サーバーの起動

```bash
npm run dev
```

`.env` の `HOST` を読み込み、ポート `3647`（`http://<HOST>:3647`）で起動します。

### 3. 本番ビルドと起動（自宅サーバー稼働）

```bash
npm run build
npm run start
```

### 4. Windows バックグラウンド起動（VBScript）

事前に `npm run build` を実行した上で、プロジェクトルートの **`start_daily-log.vbs`** をダブルクリックすると、コマンドプロンプト画面を表示せずにバックグラウンドで本番サーバー（ポート `3647`）が起動します。

- **PC起動時の自動起動**: `Win + R` → `shell:startup` で開くスタートアップフォルダに `start_daily-log.vbs` のショートカットを配置します。
- **停止方法**: タスクマネージャーから `node.exe` を終了するか、以下を実行します。
  ```powershell
  taskkill /F /IM node.exe
  ```

## スマホでのPWA利用（ホーム画面に追加）

1. スマホのブラウザから `http://<HOST>:3647` にアクセスします。
2. ブラウザのメニュー（iOS Safari は「共有」ボタン、Android Chrome は右上メニュー）から **「ホーム画面に追加」** を選択します。
3. ホーム画面に追加された `DL`（`daily-log`）アイコンからいつでも起動できます。
